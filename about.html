THE ARCHIVE

A static website concept inspired by the mystery, friendship, and retro atmosphere of Stranger Things.

PROJECT NOTE

WELCOME TO HAWKINS.

This website was designed as a student web-development project. Instead of using a childish fan-page style, the design uses a darker cinematic interface inspired by 1980s posters, horror titles, analog screens, and the red glow associated with the Upside Down.

The pages demonstrate navigation, responsive layouts, character profiles, visual galleries, and interactive hover effects using HTML and CSS.
